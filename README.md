# atalk-varejo-saas

Repositorio com as pastas `frontend` e `backend` do Atalk Varejo SaaS.

## Configuracao

Copie os arquivos de exemplo antes de rodar o projeto:

- `backend/.env.example` para `backend/.env`
- `frontend/.env.example` para `frontend/.env`

Os arquivos `.env` reais e as pastas `node_modules` nao devem ser enviados ao repositorio.
